# 📊 Crypto Tracker

A dynamic cryptocurrency tracking web application built using **React** and modern frontend tools. This project allows users to explore various cryptocurrencies, view real-time market data, and analyze historical trends through visual charts.

---

## 📌 Project Overview

The Crypto Tracker is designed to provide users with an interactive interface to:

* Browse a list of cryptocurrencies
* View current market prices
* Analyze price trends using charts
* Explore historical data of selected coins

This project was developed as part of my learning journey to strengthen my frontend development skills and understand real-world data handling.

---

## 🚀 Features

* 📃 Displays a list of available cryptocurrencies
* 🎯 Interactive slider to browse coins one by one
* 📊 Detailed view of each cryptocurrency
* 📉 Bar graph visualization for price trends
* 📅 Historical data tracking
* ⚡ Dynamic UI updates based on user interaction
